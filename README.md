# yyx-blog

这是我的个人博客，欢迎访问！

## 文章标签

博客文章每篇使用 1～2 个标签，优先复用以下主题；具体产品、比赛和事件名称写在标题或正文中。

| 标签 | 适用内容 |
| --- | --- |
| 生活 | 毕业、日常经历与生活经验 |
| 跑步 | 训练、赛事与跑步感受 |
| 游戏 | 游戏体验、作品感想与回忆 |
| 硬件折腾 | 装机、树莓派、NAS 等硬件实践 |
| 技术实践 | 软件部署、自建服务与项目分析 |
| 年度总结 | 每年的个人回顾 |

例如，NAS 文章使用“硬件折腾”和“技术实践”，半马小记使用“跑步”。新增标签前，先确认已有主题无法覆盖，且后续会持续写相关内容。

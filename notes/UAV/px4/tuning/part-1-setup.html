PX4 调参 Part 1：装机与基础设置

约 1579 字大约 5 分钟

2026-09-16

来源：PX4 Ultimate Tuning Guide - Part 1 Setup（Chris Rosser） 相关：PX4 基础概念、DIY 无人机组装与试飞记录 目标：把 PX4 无人机装好、接线、配置到可安全首飞，为后续滤波与 PID 调参打基础。

0. 选型与准备

  • 固件选择：爱好者用 PX4 或 ArduPilot 差别不大（PX4 稍简单，ArduPilot 非标构型支持更好）。商用差异大：ArduPilot 是 GPLv3，改动必须开源；PX4 是 BSD-3，可闭源二次开发。
  • 软件：从 qgroundcontrol.com 下载 QGC（本例 Windows 11，其他平台流程一致）。
  • 示例硬件：Miko Air 743 V2 飞控（约 $45，含 4in1 55A ESC 不到 $75）、AOS UL8 机架、M10 GPS+指南针、DJI O3 Air Unit 图传、ELRS 2.4 GHz 接收机。
  • 调参方法对所有尺寸机型通用（3 寸圈圈机到 100 kg 农业机）。

1. 接线

  • PX4 期望外设接在指定 UART，尽量按官方接线图接；UART 重映射不像 Betaflight 那样方便。
  • Miko Air 743 V2 注意点：
    • 最多 11 路电机/舵机输出，但只有前 4 路支持双向 DShot（芯片定时器分配限制）。
    • 数字图传插头与接收机共用 RX6：插 O3 Air Unit 时必须断开它的 SBUS 线，否则接收机永远不工作（用 ELRS 时尤其要注意）。
  • 伴飞电脑（跑代码的机载计算机）走 USB 接入。

2. 首次连接与固件

  1. USB 连接无人机，QGC 几秒后自动连上。
  2. 点左上 Q logo → Vehicle Configuration（所有首飞前设置都在这里）。
  3. Firmware 页：拔插一次，出现识别到 Pix 板的对话框后可刷最新固件（换新板建议先检查版本）。重刷后传感器/遥控器页报警告属正常。

3. 机架（Airframe）

选择最接近实机的构型（本例 Generic Quadcopter）。设置正确后 Airframe 面板指示灯变绿。

4. 传感器校准

项目要点
指南针户外远离大型金属/车辆，保证周围磁场强度与方向一致；摘掉强磁性首饰；先设飞控朝向（板上白箭头 = 机头，本例转了 180°）；按提示六面各转 360°：水平 → 倒扣 → 机头朝下 → 机头朝上 → 右侧 → 左侧，每面等指示框变黄再转至变绿；完成后重启
陀螺仪放在水平、无振动的台面，点校准后很快完成
水平校准（Level Horizon）完全水平的台面上执行，定义“水平”基准，可避免 Stabilized 模式漂移
加速度计多数飞控出厂校准已可用；若要做，必须能把机身六个面都放平静置（水平、背面、机头、机尾、左侧、右侧），先确认 autopilot orientation 没变

5. 遥控器

  1. 设协议：参数 → Serial 段，选择接收机协议（Crossfire / DSM / Ghost / SBUS / 自动识别 PPM 等），并把它设到接收机实际连接的 UART（本例 UART6）；其余 RC 输入驱动全部设为 Disabled 防止冲突；保存后 Reboot Vehicle。
  2. 先开遥控器再给无人机上电，否则 PX4 可能检测不到遥控器、不响应摇杆。
  3. 校准：Radio 页确认白点随摇杆移动 → Calibrate → 所有微调（trim）归零 → 按提示依次做：油门最低 → 油门最高/最低 → Yaw 右/左 → Roll 右/左 → Pitch 上/下 → 把所有摇杆和开关打满行程 → Next 写入参数。

6. 飞行模式与开关

  • 用三档开关（本例 CH8）：上 = Position（后期调位置用）、中 = Altitude（调油门/高度环）、下 = Stabilized（调 Rate PID 用）。
  • 解锁开关（本例 CH6）：比摇杆解锁更简单、安全、可靠。
  • 紧急停桨 Kill Switch（本例 CH5）：调参必备，异常时立即切停让飞机落在软草地上，否则不要飞。

7. 电源设置

  • 采样来源：飞控板载电压+模拟电流 → Power Module；外置采样板 → External；走 ESC 遥测 → ESC。
  • 电池节数：按实际填（本例 6S）。
  • 单体电压：LiPo 满 4.2 V / 空 3.5 V（可到 3.3 V，但 3.5→3.3 可用容量很少）；Li-Ion 需按具体电芯查（满 4.2–4.3 V，空 3.3–2.5 V）；LiHV 满 4.35 V / 空 3.5 V。
  • 分压比：板载分压出厂已设好，一般不用改。
  • 电流标定（Amps per volt）由分流电阻决定：10 mΩ → 100，20 mΩ → 50，25 mΩ → 40（有精密万用表可用 Calculate 校准）。

8. 执行器（Actuators）

  1. 先确认页面上的构型图与实机一致（电机数量、转向）。
  2. 协议选 DShot 300（不要 150/600）：PX4 的 PID 循环频率没那么高，600 无收益且更容易被噪声干扰；六轴/八轴需为第 5–8 路同样设置。
  3. Identify & Assign Motors：拆桨、插电池给 ESC 供电 → 点按钮让某个电机转 → 在图上点对应编号，逐个认完。
  4. 电机转向：
    • Props In（默认）：1、2 逆时针，3、4 顺时针；
    • Props Out（推荐）：1、2 顺时针，3、4 逆时针——急协调转弯（滚转+偏航）时后电机不用同时兼顾俯仰与偏航，控制权限更好。
    • 改向方法：DShot ESC 可在 Actuator Testing 里用 set spin direction 1/2 软件反转；或直接对调任意两根电机线。
  5. 电机位置：量前两电机间距、后两电机间距、前后间距，填对应 X/Y（例：前 31 cm → Y ±0.155；后 27 cm → ±0.135；前后 21 cm → 0.105），让 PX4 精确掌握力臂。

9. 安全设置

  • 低电量保护：15% 警告、7% 返航、5% 紧急降落（默认值合理）。
  • RC 丢失 → Return（返航）；数据链丢失不要设 failsafe，丢遥测不算致命，否则会无谓触发返航降落。
  • Geofence：最大半径 500 m（视距内）、最大高度 120 m（法规限制）。
  • 返航策略：先爬升到越障高度，回到 home 后立即降落（或 loiter / loiter 后降落）。
  • 降落：下降率默认 0.7 m/s（小机可快、大机宜慢）；落地后 1–2 s 自动上锁。
  • 打开遥测记录到飞控存储（SD 卡）；不做硬件在环仿真就保持 HITL 关闭。

10. 完成后

所有页面配置完成即可进行首次悬停测试，随后进入 Part 2 陀螺仪滤波调参（见 PX4 调参 Part 2 陀螺仪滤波流程总结）。
